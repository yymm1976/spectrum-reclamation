## 二、功能清单

1. **卸负药水** — 自定义负面效果（盔甲概率脱落 + 死亡 100% 掉落），Spectrum 药水工坊酿造
2. **炽光炸弹** — 火把花投掷物（半径 8 格发光 + 亡灵燃烧 + 方块光源 30 秒）
3. **活体陷阱** — 瓶子草荚果陷阱（捕捉 ≤0.6 体宽生物 → 释放 + 虚弱）
4. **制箭台 GUI** — Mixin 注入原版制箭台（5 槽 + 输出 16 支箭），`registerArrowRecipe()` API
5. **铜管传输** — 瞬间物品传输（BFS 路径查找 + 蜜脾防水 + 维度隔离）
6. **通用瞄准镜** — 右键附着到弓/弩（FOV 缩放 + 弹道优化）
7. **可自定义追溯指针** — 蹲下右键记录位置 + 升级版显示距离数字
8. **纹饰效果系统** — 18 种纹饰材料（原版 12 + Spectrum 6），`TrimEffectRegistry` 公开 API
9. **陨星弩 + 沉重之矛** — CrossbowItem 子类 + 钉穿机制（Slowness 254 + setDeltaMovement）
10. **墨水涂装系统** — 16 色涂装（药水工坊合成），矛击中时触发颜色对应效果

## 四、核心架构决策

| # | 决策 | 理由 |
|---|---|---|
| 1 | 事件驱动 + 属性修饰器（纹理效果） | 优于 BetterTrims 的 Mixin 模式 |
| 2 | `@Inject(at=HEAD, cancellable=true)`（制箭台） | 不破坏原方法体，多模组兼容 |
| 3 | 右键交互附着瞄准镜（非锻造台） | 保留附魔/NBT/耐久 |
| 4 | 方块光源方案（炽光炸弹） | 亮度精确可控，不依赖客户端粒子 |
| 5 | 铜管 BFS 网络 + 静态 HashMap | 简单可靠，维度物理隔离 |
| 6 | `ChargedProjectiles` 组件操作（陨星弩） | CrossbowItem 私有方法不可调用 |
| 7 | `paletted_permutations` 图集（纹饰渲染） | NeoForge 1.21.1 唯一可用方案 |

query: spectrum "bottle of ruin" OR "ruin" potion item mcmod 590534

answer:
  The Bottle of Ruin is an item from the Spectrum mod used to corrode blocks [1]. When placed, it releases a microbial block that produces an explosion effect and sound, ultimately returning a glass bottle to the player [1]. It is used for tasks such as obtaining Bedrock Powder, opening portals to the Abyss, and solving puzzles involving ancient bedrock and redstone ruins [1]. You can obtain it in-game using the command:

```
/give @p spectrum:bottle_of_ruin 16
```

The item is crafted using two Midnight Shards [2][3][1]. It is categorized as a decoration and stacks up to 16 [3][1].

获取途径

通过七彩基座制作，也可以用玻璃瓶接取已经存在的褪解微生物方块来获取。

褪解微生物

看上去像是青白色的黏土块，踩在上面的生物会每秒受到1伤害。它会侵蚀与它直接接触（不包括斜角接触）的有机方块：

树叶(#minecraft:leaves)、

南瓜、西瓜、红/棕色蘑菇方块、

蘑菇柄、干草块、干海带块、苔藓块。

| 不掉落植本质 | 由褪解之瓶直接放出的褪解微生物。 |
| --- | --- |
| 挖掘后掉落1个植本质 |
| 挖掘后掉落3~5个植本质 | 染色树的树叶、闪烁的西瓜。 |

无论褪解微生物是否是侵蚀其他方块产生的，都可以用玻璃瓶重新收集变为褪解之瓶。

“⚠️饥饿”

获取途径

通过七彩基座制作，也可以用玻璃瓶接取已经存在的蚀解微生物方块来获取。

解锁和识别

解锁七彩基座配方需要获取进度沉重的负荷、建造祭坛；

无需解锁条件即可识别蚀解微生物方块。

用途

模组里的第二种会侵蚀方块的物品，右击任意方块即可放出其蚀解微生物方块并返还玻璃瓶，用于获取坚新石。

蚀解微生物

看起来像颜色非常黑的海绵方块，踩在上面的生物会每秒受到2.5伤害。

它会侵蚀与它直接接触（不包括斜角接触）的绝大多数方块：

由蚀解之瓶直接放出的蚀解微生物；

被蚀解微生物侵蚀的其他方块。

黑曜石。

| 不掉落坚新石 |
| --- |
| 挖掘后掉落1个坚新石 |
| 挖掘后掉落3~5个坚新石 | 哭泣的黑曜石。 |

默认情况下，蚀解微生物不能侵蚀方块实体以及下列方块：

液体：包括水、熔岩、液体水晶等；

雪、基岩方块、移动的活塞、基岩；（不理解雪为什么不行）

各种传送门（#minecraft:portals）、末地传送门框架。

各类管理员方块。

蚀解微生物最多散播至曼哈顿距离15的位置，每距离源头一格都会增加一点age直到age=15就不再会散播。而被侵蚀的黑曜石将会将age设置为0并重新作为新的源头。

无论蚀解微生物是否是侵蚀其他方块产生的，都可以用玻璃瓶重新收集变为蚀解之瓶。

##### 褪解之瓶 (Bottle of Fading)

- 加合成表
- 编辑

物品命令：/give @p spectrum:bottle_of_fading 16

获取途径

通过七彩基座制作，也可以用玻璃瓶接取已经存在的褪解微生物方块来获取。

在林下庄园的地下超传魔盒谜题的充满共振铃兰的房间的保护石箱子中生成。

解锁和识别

解锁七彩基座配方需要获取进度眼见不一定为实；

无需解锁条件即可识别褪解微生物方块。

用途

模组里的第一种会侵蚀方块的物品，右击任意方块即可放出其褪解微生物方块并返还玻璃瓶，用于获取植本质。

褪解微生物

看上去像是青白色的黏土块，踩在上面的生物会每秒受到1伤害。它会侵蚀与它直接接触（不包括斜角接触）的有机方块：

树叶(#minecraft:leaves)、

南瓜、西瓜、红/棕色蘑菇方块、

蘑菇柄、干草块、干海带块、苔藓块。

| 不掉落植本质 | 由褪解之瓶直接放出的褪解微生物。 |
| --- | --- |
| 挖掘后掉落1个植本质 |
| 挖掘后掉落3~5个植本质 | 染色树的树叶、闪烁的西瓜。 |

无论褪解微生物是否是侵蚀其他方块产生的，都可以用玻璃瓶重新收集变为褪解之瓶。

##### 蚀解之瓶 (Bottle of Failing)

- 加合成表
- 编辑
- 查看

物品命令：/give @p spectrum:bottle_of_failing 16

“⚠️饥饿”

获取途径

通过七彩基座制作，也可以用玻璃瓶接取已经存在的蚀解微生物方块来获取。

解锁和识别

解锁七彩基座配方需要获取进度沉重的负荷、建造祭坛；

无需解锁条件即可识别蚀解微生物方块。

用途

模组里的第二种会侵蚀方块的物品，右击任意方块即可放出其蚀解微生物方块并返还玻璃瓶，用于获取坚新石。

蚀解微生物

看起来像颜色非常黑的海绵方块，踩在上面的生物会每秒受到2.5伤害。

它会侵蚀与它直接接触（不包括斜角接触）的绝大多数方块：

由蚀解之瓶直接放出的蚀解微生物；

被蚀解微生物侵蚀的其他方块。

黑曜石。

| 不掉落坚新石 |
| --- |
| 挖掘后掉落1个坚新石 |
| 挖掘后掉落3~5个坚新石 | 哭泣的黑曜石。 |

默认情况下，蚀解微生物不能侵蚀方块实体以及下列方块：

液体：包括水、熔岩、液体水晶等；

雪、基岩方块、移动的活塞、基岩；（不理解雪为什么不行）

各种传送门（#minecraft:portals）、末地传送门框架。

各类管理员方块。

蚀解微生物最多散播至曼哈顿距离15的位置，每距离源头一格都会增加一点age直到age=15就不再会散播。而被侵蚀的黑曜石将会将age设置为0并重新作为新的源头。

无论蚀解微生物是否是侵蚀其他方块产生的，都可以用玻璃瓶重新收集变为蚀解之瓶。

- 加合成表
- 编辑
- 查看

物品命令：/give @p spectrum:bottle_of_ruin 16

获取途径

通过七彩基座制作，也可以用玻璃瓶接取已经存在的坏灭微生物方块来获取。

解锁和识别

解锁七彩基座配方需要获取进度忧郁"蓝"调、细碎的恶；

无需解锁条件即可识别坏灭微生物方块。

用途

模组里的第三种会侵蚀方块的物品，右击任意方块即可放出其坏灭微生物方块并返还玻璃瓶，用于获取基岩粉、打开渊深之域传送门、破解远古遗迹-基岩与红石谜题。放置时会发出尖锐的爆鸣声，同时发出爆炸粒子。

本身也是合成材料，可以合成兔毒瓶装饮品、变换自如(Razing)附魔书。

坏灭微生物

看起来像更黑的煤炭块，踩在上面的生物会每秒受到5伤害。

它会侵蚀与它直接接触（不包括斜角接触）的绝大多数方块和液体，包括蚀解微生物：

由坏灭之瓶直接放出的坏灭微生物；

被坏灭微生物侵蚀的其他方块。

基岩、基岩方块

| 不掉落基岩粉 |
| --- |
| 挖掘后掉落1个基岩粉 |

默认情况下，坏灭微生物不能侵蚀方块实体以及下列方块：

雪、移动的活塞；（雪＞基岩？）

各种传送门（#minecraft:portals）、末地传送门框架。

各类管理员方块。

无论坏灭微生物是否是侵蚀其他方块产生的，都可以用玻璃瓶重新收集变为坏灭之瓶。
